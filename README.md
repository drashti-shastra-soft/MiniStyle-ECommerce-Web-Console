# 🛍️ MiniStyle – E-Commerce Web Console

**MiniStyle E-Commerce Web Console** is a responsive ASP.NET-based administration panel designed to manage and control an online shopping platform.

It provides a centralized interface for managing products, categories, sizes, inventory, orders, payments, customers, discounts, banners, and sales reports.

## 🚀 Features

- **Dashboard:** View important store information and sales reports.
- **Product Management:** Add, edit, view, and manage products.
- **Category Management:** Organize products into categories.
- **Size Management:** Manage available product sizes.
- **Inventory Management:** Track and manage product stock.
- **Order Management:** View and manage customer orders.
- **Payment Management:** Manage order payment information.
- **Customer Management:** Maintain customer records.
- **Discount Management:** Create and manage discounts.
- **Banner Management:** Manage promotional banners.
- **Role-Based Access:** Control access based on user roles.
- **Secure Authentication:** Secure login and administration access.
- **Responsive UI:** Access the admin console across different screen sizes.

## 📁 Project Structure

The solution follows a layered project structure.

```text
MiniStyle-ECommerce-Web-Console/
│
├── MiniStyleWebConsole.Domain/
│
├── MiniStyleWebConsole.Infrastructure/
│
├── MiniStyleWebConsole.Service/
│
├── MiniStyleWebConsole/
│
└── MiniStyleWebConsole.sln
```

### Project Layers

- **Domain:** Contains application domain models and related definitions.
- **Infrastructure:** Handles infrastructure and data access-related functionality.
- **Service:** Contains application service-layer functionality.
- **WebConsole:** Contains the web application and administration interface.

## ⚙️ Getting Started

### Prerequisites

- Visual Studio
- .NET SDK / Targeting Pack compatible with the solution
- MiniStyle Web API
- SQL Server (if required by the configured API/database)

### Installation

1. Clone the repository:

```bash
git clone https://github.com/drashti-shastra-soft/MiniStyle-ECommerce-Web-Console.git
```

2. Navigate to the project directory:

```bash
cd MiniStyle-ECommerce-Web-Console
```

3. Open the solution file:

```text
MiniStyleWebConsole.sln
```

4. Restore the required NuGet packages.

5. Configure the MiniStyle Web API connection settings.

6. Build and run the web application using Visual Studio.

## 🔗 Related Project

**MiniStyle Web API:** The Web Console communicates with the MiniStyle Web API for application functionality and data operations.
